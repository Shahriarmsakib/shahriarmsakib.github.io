# shahriarmsakib.github.io

Source for my academic website, **https://shahriarmsakib.github.io**, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and deployed to GitHub Pages by the `Deploy site` workflow.

| What                              | Where                                                                        |
| --------------------------------- | ---------------------------------------------------------------------------- |
| Bio, photo, news on the home page | `_pages/about.md`, `assets/img/prof_pic.jpg`, `_news/`                       |
| Publications                      | `_bibliography/papers.bib` (thumbnails in `assets/img/publication_preview/`) |
| Projects                          | `_projects/` (images in `assets/img/projects/`)                              |
| CV page                           | `_data/cv.yml`                                                               |
| Social links                      | `_data/socials.yml`                                                          |
| Site settings                     | `_config.yml`                                                                |

Template documentation is in [`docs/`](docs/).
